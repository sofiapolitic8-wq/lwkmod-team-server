david.io team server (no dependencies, Node 16+)

  node server.js            (PORT=8787 by default, teams are saved in teams.json next to it)

Friends must reach it: the game page is https, so use an https URL
(host it on any free Node host, or tunnel it:  cloudflared tunnel --url http://localhost:8787 ).
http://127.0.0.1:8787 works only for the person running it.

In game:  Open Settings (double-tap ".")  ->  "david.io Team"  ->  Team server -> paste the URL -> Save.
Then choose Team name / Group / Players and press Generate (or "Quick team").
The invite you copy already contains the server URL + name + group + size, so friends only paste it and press Join.
